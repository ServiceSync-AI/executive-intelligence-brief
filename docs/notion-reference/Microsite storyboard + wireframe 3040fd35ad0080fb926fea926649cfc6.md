# SECTION 0 — HERO (Authority & Framing)

### Purpose

Set seriousness. Establish this is *not* a recap or pitch.

### Wireframe

```
[ H1 ]
Two Days. 40+ Operators. One Pattern.

[ Subhead ]
An executive synthesis of what surfaced in the room —
and where fixed operations quietly break down.

[ Metadata ]
January 2026 · NADA 20 Group GC06 · Atlanta
Prepared independently from meeting materials, SOPs, and transcripts
```

### Design Notes

- White background
- No imagery
- Lots of whitespace
- This should feel like a McKinsey cover page

# SECTION 1 — THE ROOM (Legitimacy Without Names)

### Purpose

Show **who** this applies to without exposing anyone.

### Wireframe

```
[ H2 ]
The Room

[ One-line context ]
19 dealer organizations · single-point and multi-rooftop · mixed markets

[ Visual ]
Dealer Footprint Matrix
(anonymous dots showing scale + market diversity)

[ Caption ]
Insights drawn from a structurally diverse operator group.
```

### Psychological Effect

> “This wasn’t one store’s opinion.”

# SECTION 4 — WHERE PERFORMANCE STILL VARIES (The Tension)

### Purpose

Introduce the **problem** without blaming.

### Wireframe

```
[ H2 ]
Where Performance Still Varies

[ Visual ]
Small Multiples / Variance Panels
• Technician proficiency
• Hours per RO
• Recon days
• Parts turns
• Absorption

[ Caption ]
Same knowledge. Different outcomes.
```

### Design Notes

- No dealer names
- No rankings
- Let variance speak for itself

# SECTION 5 — DEALER COMMITMENTS (Intent Captured)

### Purpose

Show **execution intent** — this is rare and powerful.

### Wireframe

```
[ H2 ]
What Each Dealership Committed To

[ Subhead ]
Post-meeting execution priorities captured directly from the room.
Numbers indicate dealership codes.

[ Visual ]
Dealer Commitment Matrix
(rows = themes, columns = dealer numbers, dots = commitments)

[ Secondary Visual ]
Theme Density Bar
(which execution areas dominated)

[ Supporting copy ]
Despite differences in store size and market,
priorities converged quickly.
```

### Psychological Effect

> “This wasn’t just talk.”
>

# SECTION 6 — WHERE EXECUTION QUIETLY BREAKS (Core Insight)

### Purpose

Deliver the **central insight**.

### Wireframe

```
[ H2 ]
Where Execution Quietly Breaks

[ Visual ]
Execution Loop Diagram:
Decision → Owner → Action → Measurement → Follow-up

[ Highlighted breakpoints ]
• After meetings
• Between departments
• Between shifts
• Between systems

[ Copy ]
Most failures occur between steps, not within them.
The system doesn’t remember. People are forced to.
```

### This Is the Heart

This is where Greg leans forward.
